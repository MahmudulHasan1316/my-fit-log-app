1. My project Name: FitLog — Workout & Fitness Tracker

2. Description: FitLog is a modern fitness tracker built with    Next.js, React, TypeScript, and Tailwind CSS. It lets users explore workouts, create daily plans, save exercises, and track their fitness journey.

3. Technologies: 
    - Next.js
    - React.js
    - TypeScript
    - Tailwind CSS
    - daisyUI
    - JavaScript (ES6+)
    - React Context API
    - LocalStorage
    - REST API
    - Lucide React
    - React Toastify
    - Git & GitHub

4. Key Features:
    - Workout Library — Explore workouts with detailed exercise information.
    -Daily Workout Plan — Add exercises to your personalized daily plan.
    -Save for Later — Save favorite workouts for quick access.
    -Plan & Save Counters — View the number of planned and saved workouts directly from the navbar.
    -Responsive Design — Fully responsive interface for desktop, tablet, and mobile devices.
